# Data sources

The official resources for the challenge are published on 13 November 2026 on the
[challenge page](https://www.spaceappschallenge.org/2026/challenges/earth-system-trend-detective/?tab=resources).
This file will list every dataset TrendScope uses, with its access method, resolution and citation.

## Datasets named in the challenge statement

| Source | Type | Examples of variables |
|---|---|---|
| MERRA-2 | Global reanalysis model | Air temperature, humidity, wind |
| GLDAS | Land data assimilation model | Soil moisture, evapotranspiration, runoff |
| GPM (IMERG) | Satellite precipitation | Rainfall rate and totals |
| MODIS | Satellite instrument | Vegetation index (NDVI), land surface temperature |
| OMI | Satellite instrument | Ozone, nitrogen dioxide |
| AIRS | Satellite instrument | Atmospheric temperature and water vapour |

## Citation

Each dataset used in the app will be cited here and on the app's "About the data" page, following the
citation guidance on its NASA landing page.
