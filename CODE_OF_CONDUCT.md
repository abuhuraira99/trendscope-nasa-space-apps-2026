# Code of conduct

TrendScope follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
and the [NASA Space Apps values](https://www.spaceappschallenge.org/about/).

In short: be respectful, give useful feedback, and assume good intent. Harassment, discrimination or
bullying of any kind is not accepted.

Report problems to the team lead, Abu Huraira, through GitHub or the team chat. For concerns about the
wider event, contact the Multan Local Lead or conduct@spaceappschallenge.org.
